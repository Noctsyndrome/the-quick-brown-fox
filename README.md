# The Quick Brown Fox

One sentence, many worlds.

[See all versions](https://www.denkibrew.com/the-quick-brown-fox-jumps-over-the-lazy-dog)

"The quick brown fox jumps over the lazy dog" is the sentence people type to test a typewriter or preview a font, because it uses every letter of the alphabet. We have read it countless times without ever seeing it happen. This project takes it at its word: a fox runs, leaps over a sleeping dog, and lands, again and again.

Each version retells that scene in its own visual language, from a PS1-era low-poly forest and an isometric pixel diorama to a pocket LCD handheld and a curved CRT terminal drawn in ASCII. The versions don't try to match each other; the variety is the point. More styles are still brewing.
