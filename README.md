# The Quick Brown Fox

[See all versions](https://www.denkibrew.com/the-quick-brown-fox-jumps-over-the-lazy-dog)

"The quick brown fox jumps over the lazy dog" is a pangram: it contains every letter of the alphabet, so it is commonly used to test typewriters and preview fonts. This project animates the sentence literally: a fox runs, jumps over a sleeping dog, and lands, on a loop.

Each version draws the same scene in a different visual style: a PS1-era low-poly forest, an isometric pixel diorama, a four-shade pocket LCD, an ASCII terminal on a curved CRT, and a Hiroshige-style woodblock print of a winter night with fox fires. The versions are not meant to look alike; trying different styles on one fixed subject is the idea. More versions will be added over time.
